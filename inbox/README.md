# Inbox — рабочая зона (для семьи и разбора)

Сюда складываем **сырьё**: фото рукописей, сканы, черновые заметки.  
На сайт (GitHub Pages) это **не попадает** — только локально / между нами.

Опубликованный контент живёт в `content/ru/` и `content/en/`.  
Картинки для сайта потом — в `static/` или `assets/` (отдельно, отобранные).

## Папки

| Путь | Что класть |
| --- | --- |
| `inbox/scans/memoirs/` | Фото рукописных мемуаров (страницы по порядку) |
| `inbox/scans/photos/` | Семейные фото «на разбор» (подписи, даты — потом) |
| `inbox/scans/documents/` | Документы, письма, свидетельства |
| `inbox/scans/misc/` | Всё остальное |
| `inbox/transcripts/` | Расшифровки текста (черновики, пока не в `content/`) |
| `inbox/notes/` | Заметки, вопросы, «уточнить у родных» |

## Как снимать рукописи

1. Свет ровный, без блика и сильной тени.
2. Страница целиком, текст читаемый.
3. Имена файлов по порядку: `001.jpg`, `002.jpg`…  
   или `tetrad-1-str-03.jpg`.
4. Лучше не сжимать «в ноль» — нужен читаемый текст.

## Как мы работаем

1. Отец / вы кладёте пачку сканов в `inbox/scans/…`.
2. Пишете сюда в чат: «разобрать `inbox/scans/memoirs/…`».
3. Я читаю, расшифровываю → черновик в `inbox/transcripts/`.
4. После проверки факты переносим в статьи `content/ru/` + `content/en/`.

## Git

Содержимое `inbox/scans/**` (сами фото) в `.gitignore` — **не уезжает** в публичный репозиторий по умолчанию.  
Структура папок и README — в git, чтобы у всех была одна схема.

Если нужно отправить пачку мне через git — можно временно `git add -f` конкретные файлы или кинуть ссылку на диск / прикрепить в чат.
