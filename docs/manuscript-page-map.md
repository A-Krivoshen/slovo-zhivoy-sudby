## Дубль

- **Удалена original_page 068** (`pages/068.jpg`).
- Попиксельно: **068 ≡ 067, повёрнутый на 180°** (корреляция ≈ 1.0 после выравнивания).
- В control PDF осталась **corrected_page 067** ↔ **original_page 067** (в upright-виде).
- **Иная страница не пропущена:** original 069 → corrected 068, …, original 079 → corrected 078.

Маркеры `<!-- стр. 068 -->` / `<!-- p. 068 -->` на сайте **сохранены** как архивная нумерация первичного пакета; текст 067 и 068 в главе 08 — два прочтения одного и того же кадра (дубль скана).

## Порядок

Порядок **совпадает** с первичным PDF, за исключением удаления дубля 068:

- original 001–067 → corrected 001–067 (1:1)
- original 068 → *removed (duplicate of 067 @ 180°)*
- original 069–079 → corrected 068–078 (сдвиг −1)

Сверка PDF↔PDF (pdftoppm 72 dpi, z-norm correlation): match score ≥ 0.97 для всех 78 пар.

## Ориентация

Control PDF исправляет ориентацию кадров.  
Рабочая ориентация при первичной обработке: `inbox/scans/memoirs/work/orientation.log`.

**Опубликованные** изображения `static/photos/dnevnik-tt/str-*.jpg` (001–003, 007, 009, 010, 012, 015, 022–024) сверены с upright corrected pages: **все совпадают в правильной ориентации** (score ≥ 0.99, rot=0).

Сырые `pages/*.jpg` частично «вверх ногами» / боком — это ожидаемо; для чтения использовать `work/p-*.jpg` или control PDF.

| Вопрос | Ответ |
|--------|--------|

| Менять URL? | **Нет** |
| Переписывать расшифровки целиком? | **Нет** |
